### 🧠 Alzheimer's Disease Detection Using Machine Learning

[**View Repository →**](https://github.com/avelino1999/Alzheimer-Disease-Detection-Using-Machine-Learning-Technique)

MSc Data Science dissertation investigating whether clinical and lifestyle variables can be used to support Alzheimer's disease prediction without relying on MRI-based features.

The dataset contains **2,149 records and 34 features**. Multiple machine learning models were evaluated, with **Gradient Boosting achieving the highest accuracy of 94%** in the study.

**Skills demonstrated:**

* Pandas & NumPy
* Scikit-learn
* Data preprocessing
* Class imbalance handling
* Feature selection
* SHAP explainability
* Machine learning model comparison
* Classification evaluation
